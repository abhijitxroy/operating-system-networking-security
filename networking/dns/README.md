

# DNS

## Why DNS Matters

DNS is one of the most critical systems on the Internet.

Before users can access:

- Websites
- APIs
- Cloud Services
- Kubernetes Services
- Load Balancers

DNS must successfully resolve names into IP addresses.

A DNS failure can make healthy systems appear completely unavailable.
